# 건국대학교 RV.LAB — 상황별 경찰 VR

[English](Konkuk-RVLab.md) · [한국어](Konkuk-RVLab_ko.md) · [日本語](Konkuk-RVLab_ja.md)

---

## 한 줄로

건국대학교 **RV.LAB** 요청으로 만든 **Unreal Engine 5 · Meta Quest** 경찰 상황 훈련용 VR입니다.

헤드셋을 쓰면 현장에 가까운 상황을 그대로 밟아 보고,  
그 상황에서 경찰이 어떻게 대응·판단하는지 체험합니다.

코드는 연구실·의뢰 쪽 소유라 공개할 수 없습니다.

> [!IMPORTANT]
> 아래 내용은 전부 담당 교수의 **프로젝트 수행 확인서**로 뒷받침됩니다.  
아래는 **무엇을 만들었는지**, **내가 뭘 했는지**를 정리한 페이지입니다.

수행 사실은 담당 교수의 **프로젝트 수행 확인서**로 증빙합니다.

---

## 프로젝트의 이유

교실 강의나 문서만으로는  
“가스 냄새가 나는데 문이 잠겼다”, “편의점에서 손님이 난동을 부린다”  
같은 상황을 반복 연습하기 어렵습니다.

이 프로젝트는 그 간극을 줄이려고,  
**시나리오 단위 훈련 맵**을 Quest에서 돌리도록 만든 작업입니다.

목표는 다음과 같습니다.

- 상황 파악 → 접근 → 대화·제압·보호 등 **대응 흐름** 연습
- 장면마다 정해 둔 **프로토콜·판단 포인트**를 VR 안에서 한 번씩 겪어 보기
- 모바일 VR(Quest)에서도 **끊기지 않게** 돌릴 수 있을 정도의 상호작용·최적화

## 체험 흐름 (플레이어 기준)

대략 이런 루프로 돌아갑니다.

```text
시나리오 선택
    ↓
Quest 착용 · 현장 진입 (로코모션 / 인터랙션)
    ↓
이벤트 트리거 (신고 내용, NPC 행동, 위험 요소 …)
    ↓
플레이어 행동 (대화 · 수색 · 제압 · 보호 등)
    ↓
분기 · 결과 판정
    ↓
다음 단계 또는 시나리오 종료 (UI / HUD 안내)
```

엔진 쪽에서는 시나리오마다  
**로직·이벤트**, **상호작용**, **HUD/UI**, Quest용 **성능·패키징**이 묶여 있어야  
위 루프가 성립합니다.

제가 맡은 일이 그 묶음에 가깝습니다.

## 시나리오 구성

2023년에 상황 대응 시나리오 네 종,  
2024년에 물리력 행사 트랙을 이어서 작업했습니다.

| 연도 | 시나리오 | 훈련에서 다루는 축 (요약) |
|:----:|:---------|:-------------------------|
| 2023 | **가스 누출 · 자살 시도** | 위험물·인명 위기 현장 접근, 안전 확보와 대응 순서 |
| 2023 | **묻지마 범죄** | 불특정 다수 대상 돌발 상황, 현장 통제·대응 |
| 2023 | **스토킹 폭력** | 피해자·가해자 구도, 개입·보호 판단 |
| 2023 | **편의점 난동** | 실내 상업 시설, 난동 제압·주변 안전 |
| 2024 | **경찰 물리력 행사** | 초동수사 맥락에서 물리력 행사 판단·절차 체험 |

각 시나리오는 “한 판 클리어” 게임이 아닙니다.  
**그 상황에서 경찰이 밟아야 할 단계를 VR로 한 바퀴 도는** 쪽에 가깝습니다.

세부 스크립트·내부 수치·에셋 원본은 연구실 자산이라 여기에 올리지 않습니다.

## 개발을 두 번 나눈 이유

### 1차 · 2023 — 직업훈련 시나리오 세트

| | |
|:--|:--|
| 명칭 | RV.LAB VR 경찰 **직업훈련** 시뮬레이션 |
| 기간 | 2023.08.31 ~ 2023.10.05 |
| 역할 | VR 개발자 (프리랜서) |
| 근무 | 주 평균 약 **30시간** (확인서 기준) |

**확인서에 적힌 수행 업무**

- Unreal Engine 기반 **VR 상호작용 시스템** 설계·개발
- 경찰 훈련 시나리오에 맞춘 **로직 · 이벤트 시스템**
- **Oculus Quest** 대상 VR 환경 **최적화**
- **HUD / UI / UX** 정리, 조작성·안내 개선

이 단계에서는 전체 파이프라인을 다듬고,  
시나리오를 갈아 끼우기 쉬운 쪽으로 구조를 잡았습니다.

계약 범위를 넘는 디테일 수정도 같이 손봤습니다.  
그 부분을 교수님께서 좋게 보시고 **정식 연구원**을 제안해 주셨습니다.

집까지 구해 두고 계약서에 서명까지 해 둔 상태였지만,  
**집안 사정**으로 결국 가지 못했습니다.

아쉬운 선택이었고,  
지금도 가끔 “그때 연구실에 남았더라면 어땠을까” 하는 생각을 합니다.

### 2차 · 2024 — 물리력 행사 · 확장

| | |
|:--|:--|
| 명칭 | RV.LAB VR 경찰 **물리력 행사** 시뮬레이션 |
| 기간 | 2024.08.19 ~ 2024.12.05 |
| 역할 | VR 개발자 (프리랜서) |
| 근무 | 주 평균 약 **20시간** (확인서 기준) |

**확인서에 적힌 수행 업무**

- 현장 **초동수사** 및 경찰 **물리력 행사** 시나리오 개발
- 신규 훈련 시나리오 **2종 추가** 및 관련 에셋 적용
- 기존 빌드 **유지보수 · 안정화**

1차에서 깔아 둔 상호작용·이벤트 구조를 이어 받아,  
물리력·초동수사 쪽 콘텐츠를 얹고  
프로젝트를 계속 굴러가게 만든 구간입니다.

## 개발한 부문

소스를 공개하진 못하지만, 작업 범위는 대략 아래로 나뉩니다.

| 부문 | 내용 |
|:-----|:-----|
| **상호작용** | 잡기, 접근, 대화·선택, 상황 오브젝트 반응 등 Quest 컨트롤러 기준 VR 입력 |
| **시나리오 로직** | 단계 진행, 이벤트 발화, 성공/실패·다음 장면으로 넘기는 흐름 |
| **UI / HUD** | 훈련 중 안내, 조작 힌트, 시나리오 전환 시 피드백 |
| **플랫폼** | Quest 성능(프레임·드로콜·LOD 감각의 최적화), 패키징·실기 확인 |
| **콘텐츠** | 시나리오·에셋 추가, 기존 맵 유지보수 |

연구실 파이프라인 안에서  
**기획 시나리오 → UE 레벨/로직 → Quest 빌드**  
로 넘기는 쪽에 붙어 일했습니다.
